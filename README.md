# goblet2
Goblet2 is a fitness tracking app I am building in Go. Presently only the backend is in active development; frontend will follow. The name originates from the [goblet squat](https://en.wikipedia.org/wiki/Squat_(exercise)#Other) exercise, since it shares the first two letters of its name with Go, and I appreciate both Go and the goblet squat.

## Building and running

`make run`

You should have Go on your computer.
